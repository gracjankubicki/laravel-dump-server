# Install the maintained package

See the [current installation guide](../README.md#install) for the Packagist command and migration from the old package.

This package supports PHP 8.2–8.5, Laravel 12/13 and Symfony VarDumper 7.4/8. Install `gracjankubicki/laravel-dump-server`. The original package name identifies the upstream package.

The README also covers provider discovery, configuration, CLI and HTML output, local fallback, and network restrictions.
